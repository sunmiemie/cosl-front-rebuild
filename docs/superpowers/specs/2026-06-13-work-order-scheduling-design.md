# 工单排程与电路模块检验设计

## 背景

测试管理的“测试工单列表”当前承载生产测试工单、临时测试工单以及多类设备工单。需要把生产和临时之外的工单移到“测试管理 / 电路模块检验”，并在“首页”下新增“工单排程”页面。

## 导航设计

- “测试管理 / 测试工单列表”只保留“生产测试工单”和“临时测试工单”两个标签页。
- 新增“测试管理 / 电路模块检验”二级页面，使用现有系统的 Element Plus 横向标签页样式，承载 HALT-HASS、水循环、高温箱、振动台、高温高压井、模拟井以及电路板模块。
- 新增“首页 / 工单排程”二级页面，面向管理端统一排程。

## 工单排程页面

- 设备类型切换使用当前系统标准标签页样式：文字标签、蓝色下划线、白底卡片内切换。
- 首版排程范围：高温高压井、振动台、水循环、模拟井、高温箱。
- 页面不显示顶部“待排程 / 已排程 / 进行中”等状态统计块或状态选项卡。
- 页面主体采用左侧待排程工单列表、右侧周日历的布局。
- 状态只作为工单卡片和日历事件的标签展示，例如“待排程”“需重排”“已排程”。
- 视觉风格遵循当前 COSL 管理端：Element Plus 卡片、表单、按钮、浅色边框、8px 圆角。

## 数据同步

管理端排程必须写入后端数据库，不使用本地假数据。保存排程时调用与测试端一致的后端 schedule 接口，写入 `scheduled_start_at`、`scheduled_end_at`、`schedule_segments` 等字段。测试端刷新工单列表后，从同一字段恢复日历块并显示“已排程”。

五类设备的同步边界：

- 水循环：按工单保存/清除排程。
- 振动台：按工单保存/清除排程，支持多段 `schedule_segments`。
- 高温箱：按工单保存/清除排程。
- 高温高压井：按仪器保存/清除排程，支持多段 `schedule_segments`。
- 模拟井：按设备保存/清除排程。

## 验证标准

- 路由菜单层级符合方案 A。
- “测试工单列表”不再显示生产/临时之外的设备工单标签。
- “电路模块检验”显示被移出的工单标签，并包含“电路板模块”占位页面。
- “工单排程”页面使用系统标准标签页样式，不显示顶部状态统计块。
- 保存排程调用后端接口；测试端使用同一字段即可恢复“已排程”日历状态。
